# Tajer AI — Commercial Materials

## Elevator Pitch
Tajer AI is the AI sales agent for Saudi merchants. It turns WhatsApp messages into real orders using your actual catalog — without inventing prices or stock.

## Value Proposition
- Save hours every day answering the same questions
- Never miss a sale because you were offline
- Arabic-first, Saudi-market ready (Salla, Zid, local payments)
- Full control: AI suggests or acts only within the rules you set

## Ideal Customer Profile
- Sells via WhatsApp heavily
- Has a catalog (Excel, Salla, Zid, Shopify, or Instagram)
- Located in Riyadh or Jeddah
- Categories: perfume/oud, abaya, bags, cosmetics, jewelry, gifts

## Pilot Offer
1 month free + personal onboarding for the first 10 merchants.

## Demo Script (5 min)
1. Show homepage and value
2. Open Catalog (real products)
3. Open Conversations → click one → show AI reply based on catalog
4. Show "Approve & Create Order" button
5. Show Settings (automation modes)
6. Show Pricing
7. Ask for pilot interest

## Objection Handling
- "Will the AI invent prices?" → No. It only uses your catalog data. If unsure it asks or transfers to human.
- "Is it only Arabic?" → Full Arabic + English, RTL native.
- "Do I need to change my WhatsApp?" → Uses WhatsApp Business Cloud API (official).

## KPI First 90 Days
- 10 pilot merchants
- 3 paying customers
- Average AI resolution rate > 40%
- Positive testimonials collected
